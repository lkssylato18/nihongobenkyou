# nihongobenkyou

Finding the motivation to study Japanese...consistently...

A personal Japanese study website built around two ideas:

- **One path.** Content is ordered into small units, so there is always a clear "next step" instead of a menu of forks.
- **One daily queue.** Everything learned (vocab, kanji, grammar) goes into a single spaced-repetition system, so reviews are scheduled for me.

Goal: pass JLPT N3 by July 2028.

See `CLAUDE.md` for goals, design decisions and how we work on this project.
